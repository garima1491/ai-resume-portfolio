# AI Resume Portfolio Generator

An AI-assisted resume and portfolio generator built using React, TypeScript, Vite, Tailwind CSS, and Gemini AI concepts.

## 🌐 Live Demo

https://garima1491.github.io/AI-Resume-Portfolio


## 📌 Project Overview

The AI Resume Portfolio Generator helps users create a professional resume and portfolio from their resume information.

The application provides a simple interface where users can enter their personal information, education, skills, projects, certifications, and work experience. The information can then be organized into professional resume layouts.

The project demonstrates how modern web technologies and AI-assisted features can be combined to improve resume creation.

## ✨ Features

* Create and edit resume information
* Personal information section
* Education section
* Skills section
* Work experience section
* Projects section
* Certifications section
* Multiple resume templates
* ATS-style resume scoring
* AI-assisted summary generation

## 🔄 How It Works

1. The user enters resume information.
2. The application stores the information in structured form.
3. The user selects a resume template.
4. The application generates a professional resume preview.
5. AI-assisted tools can help improve summaries, skills, and bullet points.
6. The final project can be viewed through the web interface.

## 💻 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/garima1491/ai-resume-portfolio.git
```

### 2. Open the project

```bash
cd ai-resume-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The terminal will provide a local URL similar to:

```text
http://localhost:5173/
```

Open that URL in a browser.

## ⚠️ Responsible AI and Limitations

AI-generated resume content should be treated as a draft.

Users should verify:

* Skills
* Education
* Experience
* Projects
* Dates
* Companies
* Certifications
* Achievements
* Contact information

The application should not invent information that is not supported by the user's original resume.

API keys and other sensitive credentials should never be uploaded to GitHub.
